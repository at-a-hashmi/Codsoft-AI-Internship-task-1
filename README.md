# Task 1: Rule-Based Chatbot 

This is the first task of my **Artificial Intelligence Internship at CodSoft**.

## 📌 Project Overview

This project is a **simple chatbot** built using Python. It uses basic `if-else` statements to understand user input and provide appropriate responses based on predefined rules.

The goal is to demonstrate how rule-based systems can simulate natural language conversations in a structured way.

## 🚀 Features

- Responds to greetings
- Provides current time and date
- Answers daily-use questions
- Gracefully exits on "bye", "exit", or "quit"
- Structured using a while loop for continuous interaction

## 🧠 What I Learned

- Basics of rule-based logic
- User input handling in Python
- Conversation flow and condition checking
- Introduction to Natural Language Processing principle
